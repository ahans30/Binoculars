# 検出率の評価結果

計画は [protocol.md](protocol.md)、条件ごとの全数値は [results_dev.md](results_dev.md) と [results_test.md](results_test.md) を参照してください。

ここの数値は、照合先がPubMed抄録86,443件と手元のPDF665件のときのものです。**合成原稿での値で、実際の原稿での検出率ではありません。** 照合先にない文献は検出できず、この評価でも測っていません。

設定は `dev` だけで決め、決めた後に `test` で1回確認しました。

## 結論
- そのままの転用は10語以上でほぼ検出できます。8語では85〜89%です。
- 8語ごと以上の語の編集と、文の順序の入れ替えは、ほぼ検出できます。**5語ごとの編集はほとんど検出できません（0.5〜5.5%）。** 指紋（5語の連なり）が残らないためです。
- 文字の加工は、測った13種類すべてで検出率が98%以上になりました。全角、数学用英字、特殊な空白を除く10種類ではフラッグも出ます。
- LLMの強い言い換えは一致では検出できません（0%）が、言い換え検索で89〜98%を候補に挙げられます。
- 日本語からの英訳は、devとtestで差が大きく（86.2%と66.7%）、値は定まっていません。

| 指標 | 改良前 | 改良後（dev） | 確認（test） |

**言い換え候補は増えました。** 照合先をPubMedにも広げた結果で、検出率の改善と引き換えです。人間の抄録での候補には、同じ分野の文献にある似た内容の文も含まれ、不正の証拠にはなりません。

処理時間は言い換え検索ありで合成原稿1件あたり約7〜13秒です（改良前は約2〜3秒）。

## 設定の根拠（devのみ）

### 候補文書の選び方
候補を指紋の重みの上位200件に絞っていたため、短い一致しかない文献が、別の箇所で定型句を多く共有する文献に押し出されていました。原稿を100語ごとに分け、それぞれの上位20件も候補に加えました。そのまま10語の検出率が98%から99.5%になり、地の文の一致率はほぼ変わりませんでした。

### 言い換え検索の閾値
BAAI/bge-m3の文単位の類似度に、SCDG（arXiv:2608.03859）の利得を組み合わせました。出典を読ませたときに、文の予測がどれだけ楽になるかを Qwen2.5-1.5B で測る値です。本物の言い換えと地の文を分ける力（AUC）は、類似度が0.874、利得が0.964でした。

| 設定 | 軽い推敲 pubmed / library | 強い言い換え pubmed / library | 地の文 1,000語あたり | 人間の抄録 1,000語あたり |
|---|---:|---:|---:|---:|
| 類似度0.85のみ | 100% / 93% | 92.6% / 89% | 2.55 | 2.82 |
| 類似度0.82 + 利得0.6（採用） | 100% / 93% | 97.9% / 90% | 1.42 | 2.62 |

この表は本来の出典との組だけを数えた試算で、上の結果表と少し異なります。利得の確認は英語だけで、日本語の文には使っていません。モデルが読み込めないときは類似度0.85に戻し、その旨を注記します。

### 英語と日本語の間の検索
文単位の検索で、英語の文から日本語の文を探すときは閾値を0.75にしました。devでは検出率89.2%、地の文の誤検出は1,000語あたり0.2でした（通常の閾値のままでは33.8%）。CL-OSAは Wikidata への依存があるため採用していません。

testでは66.7%で、devとの差は標本のばらつきだけとは言いにくい大きさです（95%信頼区間は 55.4〜76.3% と 75.7〜92.5%）。testを見て調整はしていません。原因は調べていないので、低いほうの値を想定してください。

### 文字の加工
正規化を見直しました。アルメニア文字は全文で置き換えます。ギリシャ文字などはラテン文字の単語の中に混ざった場合だけ置き換えるので、TGFα、IFNγ、αvβ3 はそのまま残ります。

### 表示と抽出の不一致（PDF）
本文のあるページから均等に最大4ページを選び、150 dpiで描画してOCRにかけ、抽出した文字列と語の一致率を比べます。一致率が0.6未満のページをフラッグにします。

手元のPDF 120件、468ページの一致率は、中央値0.985、最小0.674で、閾値未満はありませんでした。ToUnicodeだけを書き換えた合成PDFは検出できることを確認しました。**実際にこの手口を使ったPDFでは確認していません。** 選ばなかったページは見ません。

### 引用の重なり
参考文献のDOI、PMID、題名を照合先の文献の引用一覧と比べ、同じ文献との共通が8件以上で、共通の割合（少ないほうの参考文献数に対する割合）が60%以上のときにフラッグにします。登録済みの3,000件で試すと0.47%にフラッグが出て、上位はほとんどが同じ論文の別版か、とても近い論文でした。

**検出率は測っていません。** 正解付きのデータがないためです。参考文献を照合先の文献に結び付けられない場合は数えられません。

## 限界
- 5語ごとの編集は、言い換え検索を有効にした測定をしていません。
- 地の文はAIの文章で、実際の原稿とは異なります。
- 転用の加工は人工的で、実際の転用の分布を表しません。
- 不自然な語句のチェックの検出率は測っていません（[確認結果](../integrity/results.md)）。
- 表示と抽出の不一致と引用の重なりは合成原稿の条件に含まれず、上の検出率には反映されていません。
- 測定に使った合成原稿はTXTで、PDFとDOCXの抽出の誤りは含みません。
