# 検出率の評価 プロトコル

結果を見る前に固定した計画です。変更した場合は末尾に理由とともに追記します。

## 目的
`simcheck` が、照合先にある文章の転用をどこまで検出できるかを、加工の種類ごとに測る。あわせて、転用のない文章での誤検出を測る。改良の前後を同じ条件で比べられるようにする。

照合先にない文献の検出は測らない。

## データ
データ本体は `data/detection_eval/` に保存する（購読誌PDFの抜粋を含むため共有しない）。一度作った標本は固定し、照合先が増えても同じ標本で比べる。

| 種類 | 内容 |
|---|---|
| 転用する文章 | 照合先から取り出した文章。`pubmed`（抄録）と `library`（英語のPDF）を各200件、`library_ja`（日本語のPDF）を最大100件 |
| 地の文 | `ai_threshold` のローカルモデルによる新規作成文と長文。推敲文は元の抄録が照合先にあるので使わない |
| 人間の対照 | 照合先のPubMed抄録8件をつないだ文章。その抄録自身は照合先から除外する |

文献のIDのハッシュで開発用（`dev`）と確認用（`test`）に分ける。**設定の調整には `dev` だけを使い、`test` は調整を終えた後の確認に限る。**

## 合成原稿
地の文6件の間に、同じ加工をした文章を5件入れる。文書形式はTXTで、PDFやDOCXの抽出は通らない。位置は記録し、正解とする。条件をまたいで同じ文章と地の文を使い、対応のある比較にする。

## 条件
| 群 | 条件 |
|---|---|
| そのままの転用 | 8、10、12、15、20、30、60語 |
| 語の編集（60語） | n語ごとに削除（5、8、12）、置換（5、8、12、20）、隣と入れ替え（5、10）、文の順序の入れ替え（約120語） |
| 文字の加工（60語、`pubmed`のみ） | 同形文字（キリル、ギリシャ、アルメニア）、全角、数学用英字、不可視文字（ゼロ幅、ソフトハイフン、異体字セレクタ、タグ、双方向制御、モンゴル母音区切り、結合用字）、特殊な空白 |
| LLMの書き換え（約120語） | 軽い推敲、強い言い換え、日本語からの英訳。LM Studioのローカルモデル2種を交互に使う |
| 対照 | 地の文のみ、人間の対照 |

LLMの条件と対照だけ、言い換え検索を有効にする。設定はほかの項目も既定値を使う。

## 指標
- **検出率（主要）:** 転用した文章の語の50%以上が一致した割合。95%信頼区間はWilson法。
- **正しい出典の割合:** 同じ基準を、本来の出典への一致だけで数えた割合。
- **言い換え検索の検出率:** 本来の出典に対する言い換えの候補が、転用した文章に重なった割合。
- **フラッグの率:** フラッグが1件以上出た原稿の割合。
- **地の文の一致率:** 地の文の語のうち一致とされた割合（誤検出の目安）。
- **一致の適合率:** 一致した語のうち、転用した文章に含まれる語の割合。

## 撤回論文のチェック
Retraction Watchの撤回論文200件と、撤回の記録がないPubMed文献を、書式を変えて参考文献の形にし、`find_retracted` に渡す。書式ごとの検出率と、1,000文献あたりの誤検出を求める。

## 事前の期待
- そのままの転用10語以上は、指紋の設計から検出率が100%に近いはずである。下回る場合は原因を調べる。
- 不自然な語句のチェックの検出率は測らない。リストから作ったテストは自己照合にすぎないため。

## 限界
- 地の文はAIの文章で、実際の原稿とは異なる。
- 加工は人工的で、実際の転用の分布を表さない。検出率は条件ごとの能力の目安で、実際の原稿での検出率ではない。
- 同じ地の文を繰り返し使うので、地の文の一致率の信頼区間は求めない。

## 変更履歴
- 標本の抽出: 動作確認で文献一覧の断片とOCRの断片が混ざると分かったので、結果を見る前に除外条件を加えた。日本語の文章は条件を満たす65件のみ。
- 撤回論文のチェック: 初回は本文が短すぎて参考文献の見出しが認識されず、題名の書式がすべて0%になった。評価側の不備なので、本文を参考文献の3倍の長さにして測り直した。
- 改良の設定: 候補文書の選び方、言い換え検索の照合先へのPubMedの追加、利得による再評価、英語と日本語の間の閾値を `dev` で決めた。根拠は [results.md](results.md) にある。`test` は決めた後に1回だけ測り、調整には使っていない。
- 照合先の追加: 標本は固定したまま、PMC全文とPubMed全件を加えて測り直す。設定を変える場合は `dev` だけで決め、変えた後に `test` を測る。
