# GitHub Actions で類似度チェックを動かす

原稿を `manuscripts/` に置いてプッシュすると、GitHub のランナーで類似度を確認し、PDF と HTML のレポートを Artifact として保存します。

**公開リポジトリ（フォークを含む）では動きません。** 原稿もレポートも誰でも見られるようになるため、ワークフローは失敗して止まります。公開フォークは非公開に変更できないので、使うときは別の非公開リポジトリを新しく作り、このコードをプッシュしてください。

## ローカル版との違い

| 機能 | ローカル版 | GitHub Actions 版 |
|---|---|---|
| 照合先 | PubMed抄録、手元のPDF | PubMed抄録、CCライセンスのPMC全文（`corpus/queries.txt` で指定） |
| 言い換えの候補 | あり（手元のPDFのみ） | なし |
| 原稿ページ | WordでPDF化 | LibreOfficeでPDF化。ページと行はWordと異なる場合があります |
| 一致箇所の仕分け | なし | Gemini（APIキーを設定した場合） |
| 修正案、Binocularsスコア | あり | なし |

購読誌のPDFは、契約上の問題があるのでクラウドに置きません。

## 原稿の渡り先
**原稿は GitHub に保存され、一致箇所は Google にも送信されます。** 使用者の責任で判断してください。

| 渡り先 | 渡る内容 | 残る期間 |
|---|---|---|
| GitHub のリポジトリ | 原稿の全文 | 削除するまで。**コミット履歴にも残ります** |
| GitHub の Artifact | 原稿の全文を含むレポート | 14日 |
| Google（Gemini API） | 一致箇所の原稿の文章と出典の題名 | Google の規約によります |
| NCBI | `corpus/queries.txt` の検索語だけ | — |

- Gemini API の[規約](https://ai.google.dev/gemini-api/terms)では、無料枠の入力は Google の製品改善に使われ、人が読むことがあります。機密情報を送らないよう求めているので、**未発表原稿には有料枠を使ってください。**
- 投稿前の原稿を外部に送ってよいかは、所属機関の規定や共著者の了解も確認してください。

## 準備
1. **非公開リポジトリを作り、プッシュします。** 公開リポジトリでは、原稿もレポートも誰でも見られます。ワークフローは公開リポジトリでは失敗して止まります。

   ```bash
   gh repo create リポジトリ名 --private --source . --push
   ```

   プッシュの前に `git status` で `data/` が含まれていないことを確認してください。`.gitignore` の `manuscripts/` の2行は、非公開のリポジトリでだけ消します。
2. **Gemini の API キーを登録します（任意）。** 登録しなければ、仕分けをせずに類似度だけを確認します。

   ```bash
   gh secret set GEMINI_API_KEY
   ```

   モデルを変える場合は、リポジトリの変数 `GEMINI_MODEL` を設定します。既定は `gemini-3.8-flash` です。
3. **`corpus/queries.txt` を自分の分野に書き換えます。** 1行に `pubmed: 検索式` または `pmc: 検索式` を書きます。`pubmed:` の1つの検索式で取得できるのは9,999件までです。`pmc:` は上限を超えると出版月で分けて取得します。
4. **照合先を作ります。** Actions の「照合先の更新」を手動で実行します。索引は同じリポジトリの Release（`corpus-index`）に保存され、毎月1回作り直されます。

## 使い方
1. `manuscripts/` に DOCX、PDF、TXT を置いて `main` にプッシュします。追加や変更があった文書を確認します。手動で実行すると、`manuscripts/` の全文書を確認します。
2. 実行結果のページで類似度を確認し、Artifact の `similarity-reports` からレポートを取得します。ログと概要には値だけを出し、原稿の文章は出しません。

原稿を消すときは、コミット履歴からも消す必要があります。

## 検出力
照合先は `corpus/queries.txt` の検索語で決まるので、原稿の分野から外れた検索語では検出が下がるはずです。**iThenticate の代わりにはなりません。**

## 他の人が使う場合
リポジトリをテンプレートにして、各自の非公開リポジトリと API キーで動かしてください。`data/` と、Release の索引は配布しないでください。
